          Conexión para publicar

          1. En GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
          2. Repository access: solo el repositorio de la app.
          3. Permissions → Repository → Contents: Read and write.
          4. Copia el token y pégalo aquí. Se guarda solo en este iPhone.

          Avisos de canciones nuevas

          Cuando le dedicas una canción, a Anahí le llega una notificación en su iPhone (iOS 16.4 o más reciente, con la app en la pantalla de inicio). Las canciones programadas le avisan el día que les toca, a las 8 de la mañana.

          1. Una sola vez, en GitHub: tu repositorio → Settings → Secrets and variables → Actions → New repository secret. Nombre: VAPID_PRIVATE_KEY. Valor: la clave privada que te pasó Claude.
          2. Anahí abre la app, toca Activar avisos y te manda el código que le aparece.
          3. Pega aquí ese código y toca Agregar su teléfono. Le llegará un aviso de prueba en un par de minutos.
